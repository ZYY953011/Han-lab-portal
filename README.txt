组会分组管理——负责人/组员候选规则调整版

本版在上一修正版基础上调整：

1. 负责人候选
   - 全部“博士后”
   - 当前“在籍在校”的博士生
   因此：张叶叶（博士后）可作为负责人。

2. 组内成员候选
   - 当前“在籍在校”的硕士生
   - 当前“在籍在校”的博士生
   因此：任浩奇（2026级博士生）可作为普通组员。

3. 同一组内
   - 负责人不能同时作为普通组员
   - 切换负责人时，组员列表会自动排除该负责人

4. 跨组
   - 延续原规则：同一成员默认不能重复加入多个组。

5. 数据兼容
   - 仍沿用原 meeting-groups 数据结构（masterIds 字段不改名），
     所以已经保存的四个分组不会丢失，也无需迁移数据库。
