组会分组管理功能——修正版

问题原因：
上一版 meetings.html 中“编辑分组 / 删除分组”按钮的 onclick 引号转义错误，
导致整个页面内联 JavaScript 语法中断。因此会出现：
- 组会汇报要求一直显示“加载中…”
- 成员月度计划为空
- 组会日历/历史记录为空
- 新增分组区域也不正常

重要：
这些数据并没有被删除。页面只是没有执行到从 Supabase 读取并渲染数据的代码。

替换文件：
1. pages/meetings.html
2. assets/js/backend.js

部署后：
1. 覆盖服务器对应文件
2. Ctrl + F5 强制刷新
3. 如果使用 CDN/静态托管缓存，请重新部署或清除缓存

本修正版已通过 Node.js JavaScript 语法检查。
