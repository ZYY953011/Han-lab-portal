按 id 幂等合并，重复点也安全；上传成功后本机记录自动转入备份。
① 粘贴组员发来的内容

支持两种格式：组员点「导出」得到的整段 JS/JSON 文本，或管理员自己整理的 JSON 数组。 可连续粘贴多人的内容，本页会按 id 自动去重合并（后粘贴的覆盖先粘贴的），最后一次性发布。

② 待发布清单
生成后可「复制」或「下载」，再覆盖仓库里同名文件即可。
③ 一键提交到 GitHub（可选，最省事）

填写一次后本机会记住（只存在你自己浏览器，不会写进网站）。令牌需要勾选 repo 权限： GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → 勾选 repo 生成。 提交后 GitHub Pages 约 1–2 分钟更新，全组即可见。
