本文件夹里有 **10 张 Excel 表**，对应网站 `assets/js/data/` 下 9 个数据模块（学生培养拆成了"基本信息+阶段"合并在一张表）。

每张表都带：① 标题行 ② 蓝色填写说明 ③ 黄色「示例行」（交回前请删除）④ 空白填写行。带下拉的列已设置选项，直接点选即可。

## 二、填写 3 条通用规则

1. **编号要唯一**：项目 `P1/P2…`、方法 `M1/M2…`、样品 `S1/S2…`、数据 `D1…`、报账 `E1…`、组会 `MT-2024-03-22`、学生 `ST1…`、成员 `MB1…`、成果 `A1…`、资源 `R1…`。编号会用来做"项目↔样品↔数据"的关联跳转。
2. **多值用分隔符**：成员、材料、仪器、作者等"多个值"用 **逗号** 分隔；操作步骤、注意事项、常见错误等"多行"在单元格内 **换行** 写（Alt+Enter）。
3. **关联字段填编号**：例如项目表的"关联样品ID"填 `S1,S2`，和样品表里的编号对应上，网站就能互相跳转。

## 三、交回后怎么进网站（管理员操作）

组员把填好的 xlsx 交回后，管理员（你）按以下步骤替换网站数据：

1. 打开 GitHub 仓库 `ZYY953011/Han-lab-portal` → 进 `assets/js/data/`
2. 点开对应的 `.js` 文件（如 `projects.js`）→ 右上角 ✏️ Edit
3. 把括号 `[ ... ]` 里的内容替换成新填的数据（保留字段名）
4. 底部填说明 → Commit changes → 等 1–2 分钟网站自动更新

> 如果你不想自己改 JSON，也可以把填好的 xlsx 发给我，我帮你**直接转成网站可用的 `.js` 数据文件**，你再去 GitHub 替换即可。

## 四、隐私与安全提醒（重要）

当前网站是**全公开**的，以下信息**先不要**填进表或网站上：
- 老师/同学私人手机号、家庭住址、身份证号
- 报账具体金额明细（可只留"已报销/未报销"状态）
- 学生个人敏感信息

后续接入"权限登录"版本后再放敏感内容。
